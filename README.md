# Smart Fan Power Monitoring System

Real-time measurement of voltage, current, power, and energy using Arduino and the ACS712 current sensor.

## ✅ Current Capabilities (Built So Far)
- Reads current using ACS712
- Calculates and displays voltage, current, power, and energy usage in serial monitor
- LCD output version in progress
- Measurement stability improvements using moving-average filtering
- Improved grounding and wiring techniques
- Breadboard prototype

## 🚧 Next Steps (Not Built Yet)
- Motor control with a transistor or MOSFET
- Temperature-based speed control
- PCB layout and enclosure design

## Hardware Used
- Arduino Uno
- ACS712 Current Sensor Module
- 12V DC Fan
- USB Power / Battery Pack
